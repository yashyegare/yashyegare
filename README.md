### About Me

I'm Yash Yegare, a software developer who enjoys building systems end to end, from the API layer down to the data pipelines and infrastructure that keep them running.

I mostly work with `Python`, `Java`, `FastAPI`, `Spark`, and tools around `data engineering` and `cloud deployments`. I care about writing code that's clean, practical, and easy to maintain.
